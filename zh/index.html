你好，我是 Max

我学的是编程，做电子工程师已经很多年了。我写的软件大多是给自己用的，为了解决自己真正遇到的问题。

它们几乎都跑在我家里的两台小服务器上：一台只有 1 GB 内存的 Banana Pi，还有一台兼作电视盒子的 Intel NUC。上面运行着我的 Telegram 机器人、监控、基于 Home Assistant 的智能家居，还有一个 Meshtastic 无线电节点。如果某个工具对别人也有用，我就把它整理好，写上测试和文档，发布在这里。

对了，我很喜欢猫。这只穿企鹅服的猫，就住在我那个 KDE 小部件的图标里。

我的项目

Crypto Research Labs

一个开放的实验室：我在这里检验加密货币交易想法，并公开所有结果，包括失败的。

一切始于我自己的交易机器人。我用真实价格回放了它的 7649 个信号，结果发现它判断方向还不如抛硬币。好在它只在测试交易所里交易过。我没有去调参数直到回测曲线变好看，而是搭了一个让这种把戏行不通的实验室：每个想法在检验之前先写下来，并用哈希值封存；手续费一律计入；GitHub Actions 定期用新数据把所有想法重新检验一遍。大多数想法没能通过，失败的结果和成功的一样被认真记录。

检验怎么做写在方法说明里，全部结果汇总在研究页面上，另外还有一门七种语言的新手课程。

Telegram Bot Manager

一个免费网页，直接在浏览器里设置 Telegram 机器人：webhook、命令、名称和简介、头像、菜单按钮和管理员权限。

我自己有好几个机器人，以前每改一次 webhook，就得在终端里再敲一条带着机器人 token 的 curl 命令。现在点几下就行。这个页面背后没有服务器：请求从你的浏览器直接发往 Telegram；除非你让浏览器记住，token 只保存在当前标签页里；严格的 CSP 策略不让外部脚本进入页面。没有统计分析，也没有计数器。支持五种语言，手机上也能用。

还有分步指南：设置 Webhook、用 getWebhookInfo 检查、删除 Webhook，以及机器人命令编辑器。token 如何受到保护，见 README 的隐私与安全一节（英文）。

My IP & Geo

一个 KDE Plasma 6 小部件：显示你的公网 IP 和所在国家、本地网络接口，还有带端口扫描的网络扫描器、诊断、测速、按应用统计流量和设备监控。

我想一眼就看到自己是从哪个国家连上互联网的，以及 VPN 是不是真的开着。后来，我以前在终端里运行的那些工具也陆续搬了进来。断网时，诊断功能会用大白话告诉你链路断在哪里：本机连接、路由器、DNS，还是更远的地方。在 Kubuntu 上它不需要 root 权限，不用额外安装任何东西，也没有遥测。

它会连接哪些外部服务、为什么连接，都列在 README 里（英文）。

我怎么做事

我不会在 README 里写任何自己没验证过的东西。在实验室里，验证本身就是方法的一部分；其他项目都有自动化测试，每次改动都会在 GitHub Actions 上运行。

我的项目不收集你的任何信息：没有统计分析，没有 cookie，没有广告。这个页面也不从其他网站加载任何内容，看源代码就知道。

所有代码都以 MIT 许可证开源。我会及时更新文档，也会回复提问和错误报告。
